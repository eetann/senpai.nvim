# タスク
「折りたたみ表示の調整」のタスクを整理するためのチェックリストです。
チェックリストを作成したりタスクが増えたら、ユーザーの指示がなくても編集してください。
チェックリストのタスクが完了したらユーザーの指示がなくても編集してください。

## やりたいこと

- lua/senpai/usecase/message/action_result_renderer.lua で折りたたみを`conceal_lines`を使ってやってる
- この`conceal_lines`をやる直前に、そのconceal_linesする範囲を`zf`とかによる折りたたみの方でも処理しておきたい
- 意図
    - `conceal_lines`だけだと`j`・`k`で移動する時にせっかくconcealした行にもフォーカスするので不便
    - `zf`の折りたたみだけだと見た目が微妙
    - なので、`zf`→`conceal_lines`の順で2重に折りたたみをする
- もちろんトグルにも対応させたい
