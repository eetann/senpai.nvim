## Directory Structure

```
|-- .repro/ # Minimal Neovim configuration
|-- .senpai/
|   |-- prompts/ # Rule files loaded by senpai.nvim
|-- doc/ # Documentation for the Neovim plugin
|-- lua/
|   `-- senpai/
|       |-- ...
|       `-- init.lua # Entry point for the Neovim plugin
|-- queries/ # Tree-sitter configuration used in Neovim
|-- scripts/
|   |-- doc/ # Scripts for generating Neovim plugin documentation
|   `-- test/ # Scripts for minimal Neovim plugin test setup
|-- src/
|   |-- domain/
|   |-- infra/
|   |-- presentation/
|   |-- usecase/
|   `-- index.ts # Entry point for the server-side
`-- tests/ # Tests for the Neovim plugin
```
