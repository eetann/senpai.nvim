# タスク
「AIコーディングエージェントの自動承認の実装」のタスクを整理するためのチェックリストです。
チェックリストを作成したりタスクが増えたら、ユーザーの指示がなくても編集してください。
チェックリストのタスクが完了したらユーザーの指示がなくても編集してください。

## やりたいこと

- AIコーディングエージェントのツール利用が現在は手動で実行のみになってるので、自動実行したい
- 自動実行するかどうかを設定で判断したい
- ↑設定は次の通り
    - サーバー
        - サーバー起動時にクライアント(lua)から「プラグイン設定」を受け取る
        - プロジェクトごと設定を`.senpai/agent.json`から受け取る
        - 上記の設定をマージ(プロジェクト毎の方が優先)して、honoの変数として維持する
        - 上記の処理を`/agent_settings`みたいなAPI(適切な名前があれば提案どうぞ)を実行したときもやりたい(設定の再読み込み)
        - 実装は src/index.ts の`/rules`が参考になるよ
    - src/index.ts
- ツールの手動実行箇所: lua/senpai/presentation/chat/window.lua の`on_press`
